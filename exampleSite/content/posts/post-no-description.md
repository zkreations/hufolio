This post omits the `description` front matter field entirely.

In Hufolio, the layout handles optional fields gracefully. When no description is present, the `<p class="article-description">` element is not rendered in the HTML, preventing empty paragraphs or awkward vertical gaps in both web browsers and Telegram Instant View.
