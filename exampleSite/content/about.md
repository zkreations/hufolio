Hufolio is a reusable Hugo theme designed for a minimalist, distraction-free editorial experience inspired by Telegra.ph.

## Key Features

- **Zero external dependencies:** No Node.js, npm, or complex build pipelines required.
- **Zero JavaScript:** Built entirely with semantic HTML and native CSS.
- **Telegram Instant View:** Clean and predictable HTML structure optimized for instant mobile reading.
- **Inter Typography:** High-legibility typography designed specifically for editorial content.
